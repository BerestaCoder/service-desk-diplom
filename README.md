## Конфигурация `settings.ini`

Файл содержит параметры приложения и подключения к базе данных.

### Секция `[App]`
- `secret` — секретный ключ Django (для криптографической подписи). **Не используйте значение по умолчанию в продакшене!**
- `debug` — режим отладки (`true`/`false`). Включен только для разработки.

### Секция `[Database]`
Параметры подключения к PostgreSQL:
- `name` — имя базы данных
- `user` — имя пользователя
- `password` — пароль
- `host` — хост БД (стандартный: `localhost`)
- `port` — порт (стандартный: `5432`)
